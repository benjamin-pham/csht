# 🎙️ Thư Mục Transcript

Thư mục này chứa toàn bộ nội dung bài giảng, lời giảng trực tiếp của giảng viên trong các buổi học (được ghi lại dưới dạng văn bản - transcript). Đây là nguồn tài liệu quan trọng để tra cứu lại các kiến thức, dặn dò chi tiết hoặc những phần giải thích chuyên sâu không có trong slide bài giảng.

## 📂 Cấu trúc thư mục

Thư mục bao gồm các thư mục con tương ứng với từng buổi học. Mỗi thư mục con sẽ chứa file transcript định dạng `.vtt` và các file tổng hợp cấu trúc/nội dung đi kèm (ví dụ: `.vtt.structure.md`).

## 📄 Các định dạng file trong mỗi buổi học:

*   **`Buổi X.vtt`**: File chứa toàn bộ lời thoại (transcript) gốc của buổi học cùng với mốc thời gian (timestamp).
*   **`Buổi X.vtt.structure.md`** (nếu có): File tóm tắt, sắp xếp lại cấu trúc nội dung chính đã được nói đến trong file transcript tương ứng giúp dễ theo dõi và tra cứu.
