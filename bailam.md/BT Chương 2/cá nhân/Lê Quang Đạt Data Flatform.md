**Khái niệm và vai trò của Data Flatform**

## 1. Khái niệm

> Data Platform (Nền tảng dữ liệu) là tập hợp các công nghệ, dịch vụ và
> quy trình giúp doanh nghiệp thu thập, lưu trữ, xử lý, quản lý, phân
> tích và khai thác dữ liệu từ nhiều nguồn khác nhau.
>
> Đây là nền tảng trung tâm giúp dữ liệu được sử dụng hiệu quả cho báo
> cáo, phân tích, trí tuệ nhân tạo (AI) và hỗ trợ ra quyết định.

## 2. Vai trò

> Data Platform có vai trò:

- Thu thập dữ liệu từ nhiều nguồn (Website, ERP, CRM, IoT\...)

- Lưu trữ dữ liệu tập trung

- Làm sạch và chuẩn hóa dữ liệu

- Đảm bảo dữ liệu chính xác, bảo mật

- Phục vụ báo cáo và phân tích dữ liệu

- Hỗ trợ AI, Machine Learning và Business Intelligence (BI)

- Giúp doanh nghiệp đưa ra quyết định dựa trên dữ liệu (Data-driven)

## 3. Đặc điểm kỹ thuật

### Thu thập dữ liệu (Data Ingestion)

- Kết nối nhiều nguồn dữ liệu

- Thu thập theo thời gian thực (Real-time)

- Thu thập theo lô (Batch)

> Ví dụ:

- Website

- Camera

- Máy chấm công

- ERP

- CRM

### Lưu trữ dữ liệu

> Có thể sử dụng:

- Database

- Data Warehouse

- Data Lake

> Đảm bảo:

- Dung lượng lớn

- Khả năng mở rộng

- Sao lưu dữ liệu

### Xử lý dữ liệu

> Bao gồm:

- ETL (Extract - Transform - Load)

- ELT

- Làm sạch dữ liệu

- Chuẩn hóa dữ liệu

### Quản trị dữ liệu (Data Governance)

- Phân quyền truy cập

- Theo dõi lịch sử dữ liệu

- Đảm bảo chất lượng dữ liệu

- Tuân thủ các quy định bảo mật

### Phân tích dữ liệu

> Cung cấp dữ liệu cho:

- Dashboard

- Báo cáo

- Business Intelligence

- AI

- Machine Learning

## 4. Công nghệ phổ biến

> Một số công nghệ thường gặp:

### Cơ sở dữ liệu

- MySQL

- PostgreSQL

- SQL Server

- Oracle

### Data Warehouse

- Snowflake

- Amazon Redshift

- Google BigQuery

### Data Lake

- Hadoop

- Amazon S3

- Azure Data Lake

### ETL

- Apache NiFi

- Talend

- Informatica

- Apache Airflow

### Phân tích dữ liệu

- Power BI

- Tableau

- Apache Spark

## 5. Lợi ích đối với doanh nghiệp

- Quản lý dữ liệu tập trung

- Tăng tốc độ truy xuất dữ liệu

- Hỗ trợ ra quyết định chính xác

- Giảm dữ liệu trùng lặp

- Đảm bảo an toàn dữ liệu

- Nâng cao khả năng phân tích và dự báo

- Là nền tảng cho chuyển đổi số và AI

# Ví dụ thực tế

> Một công ty bán hàng có dữ liệu từ:

- Website

- Facebook

- Shopee

- Cửa hàng

- Phần mềm kế toán

> ➡ Data Platform sẽ:

1.  Thu thập toàn bộ dữ liệu.

2.  Lưu trữ vào kho dữ liệu.

3.  Làm sạch dữ liệu.

4.  Tổng hợp doanh thu.

5.  Hiển thị Dashboard bằng Power BI.

6.  Dự báo doanh số tháng tiếp theo bằng AI.
