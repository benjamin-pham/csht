# Ma trận 5 lớp năng lực × 5 thành phần

| **Lớp năng lực**                   | **Phần cứng (HW)**                                                                                | **Phần mềm (SW)**                                                                                               | **Mạng (Network)**                                                         | **Quản trị (Governance/Ops)**                                                                | **Bảo mật (Security)**                                                                        |
| ---------------------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **(1) Compute & Connectivity**     | Server/PC, storage, switch/router/firewall, endpoint; (cloud tương đương: compute/storage fabric) | OS nền, hypervisor, SDN/storage software                                                                        | LAN/WAN, VPC/VNET, SD-WAN, VPN, DNS, LB cơ bản                             | Chuẩn cấu hình, inventory/asset, capacity baseline                                           | Hardening, segmentation nền, firewall baseline, TLS/VPN, firmware/patch                       |
| **(2) Ops Platform**               | Máy chạy tool/agent (nhẹ), tận dụng (1)                                                           | Monitoring/observability, ITSM, CMDB, patching/orchestration, backup/DR tooling, IaC/automation, FinOps tooling | Telemetry/log/metric pipeline; management plane                            | Incident/Change/Problem, SLO/SLA, DR drills, capacity planning, cost control, chuẩn vận hành | Audit/log integrity, kiểm soát quyền admin, quy trình vá lỗi, cảnh báo an ninh vận hành       |
| **(3) Security + Identity**        | Appliance/sensor, HSM/TPM (nếu có), firewall/WAF (on-prem)                                        | IAM/SSO/MFA, PAM, EDR/XDR, SIEM/SOAR, DLP, KMS, vuln mgmt                                                       | ZTNA/VPN, IDS/IPS, WAF path, segmentation/Zero Trust                       | Policy, risk/compliance, access review, IR playbook                                          | Lớp “bao trùm”: identity + policy + detection/response cho (1)-(5)                            |
| **(4) App & Integration Platform** | Compute nền (1)                                                                                   | Middleware/ESB, API Gateway, microservices, container/K8s, service mesh (tuỳ), message queue/event bus          | Ingress/egress, routing nội bộ, service discovery, LB, API traffic control | CI/CD, release/change, versioning API, SRE practice, app observability                       | AuthN/Z (OIDC/SAML), secrets mgmt, runtime security, API security/WAF, image scanning         |
| **(5) Data Platform**              | Storage/compute mạnh IO; tận dụng (1)                                                             | DBMS, DW/Lake/Lakehouse, ETL/ELT, streaming, catalog/lineage, MDM, DQ tooling                                   | Ingest/replication, batch/stream movement, kết nối nguồn                   | Data governance, stewardship, retention, data quality rules, metadata standards              | Encryption at-rest/in-transit, KMS, masking, row/column security, DLP, audit truy cập dữ liệu |
